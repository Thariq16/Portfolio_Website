# Thariq Hamad: visual identity

**Positioning:** Senior Product Manager, zero-to-one builder, measured in revenue. Serves hiring managers and founders across KSA and the GCC.
**Mood:** a printed ledger, not a startup template. Paper, ink, one green, serif headlines, mono labels, hairline rules.

## Logo system

- **Primary:** the lockup (`lockup-ink.svg` on paper, `lockup-ivory.svg` on night): TH tile + "Thariq Hamad".
- **Symbol:** `monogram-green.svg` (light), `monogram-night.svg` (dark), `monogram-paper.svg` (on photos / print). Favicons, app icons, avatars.
- **Wordmark:** `wordmark-ink.svg` / `wordmark-ivory.svg` where the tile would repeat the name.
- **Ledger rule:** the short green rule under the type is the signature. It is the same hairline used for section dividers across the site.
- **In code:** `<Monogram />` (`src/components/brand/Monogram.tsx`) uses `--primary` / `--primary-foreground`, so it inverts with the theme.
- **Tested:** legible at 16px (favicon), reproducible in one colour (paper on green, ink on paper), distinct silhouette (high-contrast serif T and H on a rounded square).
- **Clear space:** at least the height of the "H" crossbar to the tile on every side. Minimum size 16px (tile), 96px wide (wordmark).
- **Don't:** recolour outside the palette, set the monogram in another typeface, add effects or gradients, stretch, or place the green tile on a green or photo ground without the paper variant.

cd identity/logo && node build-logo.mjs   # needs fontkit + @fontsource-variable/fraunces
